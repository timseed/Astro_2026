# Image Utils 

  - get_blob 
    - Using IndiServer this intercepts the CCD camera defined in the C++ code, and will auto save them. This is useful for "stealing" Focuser images without using KStars/Ekos settings. 
  - read_fits
    - A Simple Fits Reading Program 
  - StarSize
    - Calculates the Star size using SEX (Which needs to be already installed)
