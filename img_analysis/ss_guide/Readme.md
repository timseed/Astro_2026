# SS Based Image Analysis 

Instead of using StellarSolver for plate solving, I am using it for HFR and Star calculations. 

## Why ??

I think(hope) this will allow me to tune the KStars Auto guiding algorithm better, as HFR and minimum star size is a critical factor in the detection (SEP) or stars. 

## Requirements

This project needs a few other items installed 

  - cfits  (Binary)
  - stellarsolver (Src)
  - DC1394 I(Binary)
  - QT6 Compiler  

The CMake will check for these things
